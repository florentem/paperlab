# Команды

[English version](../COMMANDS.md)

Полный справочник. Всё, что здесь есть, работает; всё, чего нет, — не существует.

Обозначения: `<обязательное>`, `[необязательное]`, `а|б` — выбор.
Столбец «ядро» отмечает команды, которым нужен наш форк Paper: на чистом Paper они
либо отсутствуют, либо работают частично.

**Быстрая карта.** `/carpet` — правила и наши собственные инструменты. Всё, что есть
в Carpet, живёт под теми же именами на верхнем уровне и продублировано под `/carpet`
не будет: расхождение с модом ломает мышечную память, а это дороже единого входа.

| | Команда | Ядро |
|---|---|---|
| правила | [`/carpet`](#carpet--правила) | частично |
| наблюдатель | [`/ghost`](#ghost--наблюдатель) | да |
| трасса спавна | [`/labspawn`](#labspawn--трасса-спавна) | да |
| статусы чанков | [`/labchunks`](#labchunks--статусы-чанков) | нет |
| подписки HUD | [`/log`](#log--подписки-в-таб-лист) | нет |
| счётчики воронок | [`/counter`](#counter--счётчики-воронок) | нет |
| боты | [`/player`](#player--боты) | **да** |
| тики | [`/tick`](#tick--тики) | **да** |
| места спавна | [`/perimeterinfo`](#perimeterinfo--места-спавна) | нет |
| состояние блока | [`/info block`](#info-block--состояние-блока) | нет |
| расстояние | [`/distance`](#distance--расстояние) | нет |
| запись сигналов | [`/capture`, `/playback`, `/cplay`](#capture--playback) | **да** |

## `/carpet` — правила

Псевдоним: `/lab`. Только правила и наши инструменты, как `/carpet` в самом моде.

```
/carpet                                   изменённые правила, версия, метки
/carpet list                              все правила
/carpet list <метка>                      правила с меткой
/carpet list defaults                     что применится после перезапуска
/carpet <правило>                         карточка правила
/carpet <правило> <значение>              установить — до перезапуска
/carpet setDefault <правило> <значение>   установить и запомнить
/carpet removeDefault <правило>           забыть сохранённое
/carpet perms                             права и какие из них есть у тебя
```

Метки: `bot`, `command`, `creative`, `experimental`, `redstone`, `tick`, `tnt`.

Правила описаны отдельно — [RULES.md](RULES.md). Главное про них в двух строках:
**обычная установка не переживает перезапуск**, и это не перестраховка. Забытое
правило молча портит все последующие замеры: числа получаются правдоподобные и ни
с чем не сопоставимые. Чтобы значение осталось — `setDefault`.

Наши инструменты доступны и здесь, и отдельными командами:

```
/carpet ghost   =  /ghost
/carpet spawn   =  /labspawn
/carpet chunks  =  /labchunks
/carpet cplay   =  /cplay
```

## `/ghost` — наблюдатель

Игрок перестаёт влиять на симуляцию, но продолжает взаимодействовать с миром:
блоки ставятся и ломаются, контейнеры открываются, кнопки нажимаются.

```
/ghost              переключить у себя
/ghost <игрок>      переключить у другого        (paperlab.ghost.other)
```

Что именно отключается: чанки не тикают, мобкап не занимается, EAR мобов не будится,
мобы не выбирают наблюдателя целью, другие игроки его не видят.

**Включение не мгновенное.** Снятие уже выданных тикетов у Moonrise отложенное,
сходится примерно за 30 секунд; выключение — за секунды. Команда об этом
предупреждает.

Без нашего ядра режим частичный: мобкап, EAR и внимание мобов остаются. Команда и
об этом скажет — красным, чтобы не приняли частичный режим за полный.

## `/labspawn` — трасса спавна

Отвечает на «почему ферма не спавнит». Движок не сообщает, на каком шаге остановилась
попытка, а причин несколько и они разного смысла.

```
/labspawn                     сводка
/labspawn on | off            включить или выключить сбор
/labspawn reset               обнулить счётчики
/labspawn <категория>         только одна категория мобов
```

Категории: `monster`, `creature`, `ambient`, `axolotls`, `underground_water_creature`,
`water_creature`, `water_ambient`, `misc`.

```
spawn monster  cap 113307 · passes 4 · position 0 · plugin 0 · spawned 1
spawn ambient  cap 0 · passes 113311 · position 479805 · plugin 0 · spawned 0
```

У монстров всё упирается в кап; у ambient кап свободен, но не проходит позиция.
Столбец `plugin` — единственная причина, которой в чистом Paper быть не должно.

**Единицы разные, складывать столбцы нельзя:** `cap` и `passes` считаются на проход
«чанк × категория», остальные — на каждую пробуемую позицию.

Без нашего ядра остаётся только «появилось / отменено», без разбора причин.

## `/labchunks` — статусы чанков

```
/labchunks                    вокруг себя
/labchunks <игрок>            вокруг другого
/labchunks hello              включить карту для клиента с ChunkDebug
/labchunks hello <игрок>      то же для другого
```

Показывает, сколько чанков в каждой стадии: `INACCESSIBLE`, `FULL`, `BLOCK_TICKING`,
`ENTITY_TICKING`. Именно на границе `BLOCK_TICKING` и `ENTITY_TICKING` живут
механики, ради которых затевался стенд.

## `/log` — подписки в таб-лист

Значение висит в таб-листе и обновляется само. Ничего не пишется в чат — намеренно.

```
/log                          список логгеров с кнопками
/log <логгер>                 включить или выключить
/log <логгер> <опция>         включить с опцией
/log <логгер> <опция> full    подробный вариант, где он есть
/log <логгер> clear           снять все подписки этого логгера
/log clear                    снять всё
```

| Логгер | Опции | Что показывает |
|---|---|---|
| `tps` | — | TPS и MSPT, считаются как в Carpet |
| `mobcaps` | `[ник] [full]` | **локальный** мобкап игрока или бота |
| `counter` | `<цвет> [full]` | счётчик воронки |
| `spawn` | `[категория]` | трасса спавна |
| `item` | `despawn`, `die`, `create` и через запятую | жизненный цикл предметов |
| `microtiming` | `merged`, `all`, `unique` | микротайминги редстоуна; нужно правило `microTiming` |
| `movement` | селектор, напр. `non_zero:@a[distance=..10]` | раскладка расчёта движения |

**Отличие от Carpet.** Там подписка на логгер одна; у нас их может быть несколько —
по одной на цель. Это нужно, чтобы держать в HUD мобкапы сразу нескольких игроков
и ботов. Повторная команда с той же целью выключает подписку, с другим флагом —
заменяет.

**Мобкапы — самое важное здесь.** На Paper с `per-player-mob-spawns` спавн гасит
локальный кап каждого игрока, а мировая сумма справочная. Поэтому `/log mobcaps`
показывает настоящий кап, а мировые цифры MiniHUD от него законно отличаются.

Из консоли команда отвечает `For players only` — как в Carpet.

## `/counter` — счётчики воронок

Воронка, направленная в шерсть, считает всё, что через неё прошло. Цвет шерсти —
имя счётчика.

```
/counter                      все счётчики этого мира
/counter <цвет>               подробно: предметы, штук в час
/counter <цвет> reset         обнулить один          (paperlab.counter.edit)
/counter reset                обнулить все           (paperlab.counter.edit)
/counter scan [радиус]        найти воронки вокруг   (paperlab.counter.edit)
```

Радиус сканирования 1–64, по умолчанию 16.

## `/player` — боты

Настоящие `ServerPlayer` без клиента. Регистрируется **ядром**: нужны ванильные типы
аргументов и вызов `doTick()` в фазе соединений — ровно там и в том же порядке
относительно `tick()`, что у живого игрока. Плагином это недостижимо.

```
/player list
/player <ник> spawn [at <x y z>] [facing <yaw pitch>] [in <измерение>] [<режим>]
/player <ник> kill
/player <ник> stop
/player <ник> ghost
```

Бот наследует от вызывающего позицию, взгляд, измерение, режим игры и полёт —
всё, что не задано явно.

**Действия** — с ритмом:

```
/player <ник> attack     [once | continuous | interval <тиков>]
/player <ник> use        [once | continuous | interval <тиков>]
/player <ник> jump       [once | continuous | interval <тиков>]
/player <ник> drop       [once | continuous | interval <тиков>]
/player <ник> dropStack  [once | continuous | interval <тиков>]
/player <ник> swapHands  [once | continuous | interval <тиков>]
```

**Движение, взгляд, поза:**

```
/player <ник> move forward|back|left|right|stop
/player <ник> turn left|right|back|<yaw pitch>
/player <ник> look north|south|east|west|up|down|<yaw pitch>
/player <ник> sneak | unsneak | sprint | unsprint
/player <ник> hotbar <1-9>
```

Ход держится, пока его не сменят: это «клавиша зажата», а не шаг. Значения кладутся
в `zza` и `xxa` — те же поля, куда живому игроку пишет обработчик пакетов движения, —
и пишутся каждый тик, потому что движок обнуляет их по ходу тика.

**Транспорт и смерть:**

```
/player <ник> mount [anything]     лодки, вагонетки, лошади
/player <ник> dismount
/player <ник> respawn on|off
```

Автореспавн поднимает бота через секунду на месте создания. Без него ночной прогон
обрывается на первой смерти: клиента у бота нет, некому прислать запрос на возрождение.

**Имена.** Бот с именем живого игрока занимает его UUID, и сам игрок войти уже не
сможет. На этот случай есть правило `fakePlayerNameSuffix`: имена расходятся, а скин
берётся по имени **без** суффикса — бот выглядит как нужный игрок и никому не мешает.

## `/tick` — тики

Ванильная команда, к которой ядро дописывает два узла. Всё остальное в `/tick` —
ванильное и работает как обычно.

```
/tick toggle              заморозить или отпустить, одной кнопкой
/tick warp <время>        прогнать вперёд
/tick warp stop           прервать прогон
```

`toggle` существует ради клавиши: `freeze` и `unfreeze` на одну кнопку не повесить.

Доступность узлов управляется правилом `tickCommandCarpetfied`. Выключение не убирает
их из дерева, а делает недоступными — как в Carpet.

---

## `/perimeterinfo` — места спавна

Сколько в сфере спавна мест, где моб вообще может появиться.

```
/perimeterinfo                вокруг себя
/perimeterinfo <x y z>        вокруг точки
```

Отвечает на «почему ферма недобирает»: если вокруг тысячи пригодных мест, ферма
конкурирует с ними за один кап.

**Отличие от Carpet.** Мы обходим только **загруженные** чанки. Carpet читает блоки
как есть и подгружает мир; нам так нельзя — подгрузка меняет то самое, что мы меряем.
Сколько чанков пропущено, пишется рядом с результатом: иначе число легко прочитать
как полное.

---

## `/info block` — состояние блока

```
/info block                   блок под ногами
/info block <x y z>           конкретный блок
```

Состояние и свойства, свет, запланированные тики блока и жидкости, данные тайл-энтити.

## `/distance` — расстояние

```
/distance <x y z>                        от себя до точки
/distance <x1 y1 z1> <x2 y2 z2>          между двумя точками
```

По осям, прямое, плоское и по клеткам.

## Capture & Playback

Серверная часть протокола мода
[Capture & Playback](https://modrinth.com/mod/capture-playback). Запись изменений
блоков и редстоуновых сигналов в регионе и воспроизведение их обратно.

```
/capture start <имя> <x1 y1 z1> <x2 y2 z2>     начать запись региона
/capture stop <ассет>                           остановить
/capture list                                   что пишется сейчас
```

```
/playback start <ассет> [<задержка в тиках> [<повторов>]]
/playback stop <ассет>
/playback stopAll
/playback list
```

```
/cplay                    сводка
/cplay status             состояние моста с ядром
/cplay assets             список композиций
```

Композиции лежат в `plugins/PaperLab/cplay/assets/`, имена файлов задаёт сервер по
UUID. Клиент с модом синхронизируется сам, если у игрока есть право `paperlab.cplay`.

Воспроизведение сигналов требует ядра: подмена сигнала живёт в `SignalGetter`,
а порядок событий блоков — в цикле `runBlockEvents`. Без ядра команды остаются, но
сигналы в мир не попадут.
